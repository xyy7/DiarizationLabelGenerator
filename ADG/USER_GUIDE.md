## 快速开始

### 1. 安装和运行

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 在浏览器中打开 http://localhost:3000
```

### 2. 基本工作流程

1. 点击「创建新项目」开始使用
2. 导入音频文件
3. 添加说话人通道
4. 在时间轴上标记标签
5. 导出标签和字幕

## 功能概览

### 主界面

应用分为三个主要区域：

1. **顶部栏** - 项目名称、导入导出功能
2. **左侧侧边栏** - 音频文件列表、通道管理
3. **主内容区** - 音频播放器、标签编辑

## 详细使用说明

### 1. 项目管理

#### 创建项目

- 第一次打开时，点击「创建新项目」按钮
- 项目会自动保存到浏览器本地存储
- 下次打开时会自动恢复上次的项目

#### 项目名称

- 点击顶部项目名称可以修改
- 修改后会自动保存

### 2. 音频文件管理

#### 导入音频

- 点击左侧「导入音频文件」按钮
- 选择一个或多个音频文件（支持 MP3、WAV、OGG 等常见格式）
- 导入后的音频会显示在左侧列表

#### 切换音频

- 在左侧列表中点击任意音频文件即可切换
- 当前播放的音频会高亮显示

### 3. 音频播放控制

#### 播放/暂停

- 点击播放器中心的「播放」或「暂停」按钮
- 或者使用空格键（键盘快捷键）

#### 快进快退

- 点击「⏪」或「⏩」按钮快进/快退 5 秒
- 或使用左/右方向键
- 上/下方向键快进/快退 10 秒

#### 音量调节

- 拖动音量滑块调整音量
- 范围 0-100%

#### 播放速度

- 可以使用预设的速度按钮（0.5x、1x、1.5x、2x）
- 或拖动速度滑块精细调整
- 或使用 1-4 数字键快速切换

#### 进度控制

- 直接在波形图上点击跳转到任意位置
- 或在播放器底部拖动

### 4. 说话人通道管理

#### 添加通道

- 点击左侧「添加说话人」按钮
- 每个通道默认命名为「说话人 N」，N 为通道序号

#### 修改通道名称

- 点击通道顶部的名称
- 在弹出的输入框中编辑
- 按回车或点击外部保存

#### 删除通道

- 点击通道右上角的删除按钮
- 确认后删除通道及其所有标签和字幕

### 5. 标签编辑

#### 创建标签

1. 确保选择了正确的说话人通道
2. 在通道的时间轴上按住鼠标左键拖动
3. 释放鼠标即可创建新标签
4. 新标签默认文字为「新标签」

#### 编辑标签文字

**方法一：快速编辑**
- 点击标签上的编辑按钮（✏️）
- 在标签上直接输入文字
- 按回车或点击外部保存

**方法二：设置弹窗**
- 双击标签或点击标签设置按钮（⚙️）
- 在弹窗中编辑文字和精确时间
- 点击「确定」保存

#### 调整标签时间

**方法一：拖动**
- 拖动标签整体移动位置
- 拖动标签左/右边缘调整开始/结束时间

**方法二：精确编辑**
- 打开标签设置弹窗
- 直接输入开始和结束时间（以秒为单位）
- 支持精确到小数点后两位

#### 删除标签

- 点击标签右上角的删除按钮
- 确认后删除

#### 标签导出

- 点击顶部「导出标签」按钮
- 选择保存位置
- 导出格式为 JSON

#### 标签导入

- 点击顶部「导入标签」按钮
- 选择之前导出的 JSON 文件
- 标签会创建为新的通道

### 6. 字幕编辑

#### 切换到字幕视图

- 点击通道的「字幕」标签页

#### 添加字幕

- 点击「添加字幕」按钮
- 新字幕会添加到列表中

#### 编辑字幕

- 直接在表格中修改
- 开始时间、结束时间和内容都可编辑

#### 删除字幕

- 点击字幕行右侧的删除按钮
- 确认后删除

#### 导入 SRT

- 点击导入按钮，选择 SRT 文件
- 字幕会自动添加到当前通道

#### 导出 SRT

- 点击导出按钮
- 选择保存位置
- 文件格式为 SRT

## 常见问题

### Q: 支持哪些音频格式？

A: 支持浏览器原生支持的音频格式，主要是：
- MP3
- WAV
- OGG
- M4A（部分浏览器）

### Q: 项目数据保存在哪里？

A: 保存在浏览器本地存储（localStorage）中，关闭浏览器后数据不会丢失。
但**注意**：清空浏览器缓存或隐私数据会删除项目数据，建议定期导出标签。

### Q: 如何备份项目？

A:
1. 定期导出标签文件保存到本地
2. 可以导出多个通道的标签
3. 可以导出字幕文件

### Q: 大文件音频处理慢怎么办？

A: 当前版本对于大文件可能加载较慢，建议：
- 使用较短的音频文件进行测试
- 后续版本会优化大文件处理

### Q: 标签导出的 JSON 格式是什么样的？

A: 格式如下：

```json
[
  {
    "channelId": "xxx",
    "channelName": "说话人 1",
    "labels": [
      {
        "id": "xxx",
        "channelId": "xxx",
        "startTime": 5.2,
        "endTime": 12.8,
        "text": "开场白"
      }
    ]
  }
]
```

### Q: SRT 字幕格式是什么样的？

A: SRT 格式如下：

```
1
00:00:05,200 --> 00:00:08,500
欢迎大家来到今天的会议

2
00:00:09,000 --> 00:00:12,800
我来介绍一下项目的进展情况
```

### Q: 可以同时导入多个音频吗？

A: 可以！在文件选择对话框中按住 Ctrl/Cmd 或 Shift 键多选文件即可。
